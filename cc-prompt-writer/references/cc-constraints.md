# CC constraints

Вставляється **дослівно** в кожен згенерований Claude Code артефакт (CLAUDE.md, agent-дефініцію, task-промпт) — у відповідну секцію (CLAUDE.md → окремий розділ; task-промпт → блок наприкінці). Єдине джерело: міняється тут, підхоплюють усі режими. Це стандарт Марка для всіх CC-промптів.

Це **не** те саме, що Cowork shared-constraints — інший рантайм. Тут правила про файли, /code-search, git, сабагенти; там — про конектори і confirm-before.

---

```
## Reading rules / token optimization
- Читай лише релевантні файли. Спершу `/code-search` для пошуку, не сліпий обхід дерева.
- Не перечитуй CLAUDE.md — він уже в контексті.
- Не вантаж великі файли цілком, якщо вистачає фрагмента; читай по діапазону рядків.
- Не дублюй контекст і не переказуй уже відоме. Compressed prose: імператив, без вступів/підсумків, один факт — один раз.
- Перед записом — переконайся, що зміни мінімальні й точкові; не роздувай рішення.
- Мутуюча дія → звірка з реальним станом (re-read зміненого, тест), не з припущенням.
```

---

## Чому так

- **Reading rules** — Claude Code легко зливає бюджет контексту на зайвому читанні дерева і повторному читанні CLAUDE.md. `/code-search` дешевший за обхід.
- **Compressed prose / token-opt** — стандарт Марка для всіх CLAUDE.md і промптів; коротший harness = точніший агент.
- **Мінімальні точкові зміни** — захист від роздування 50 рядків у 500.
